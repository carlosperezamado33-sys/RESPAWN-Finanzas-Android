# Xerar APK

Con Android Studio:
1. Abrir esta carpeta como proxecto.
2. Esperar a que remate Gradle Sync.
3. Instalar SDK/API 37 se Android Studio o solicita.
4. Build > Build APK(s).
5. APK debug:
   `app/build/outputs/apk/debug/app-debug.apk`

Para un APK distribuíble definitivo haberá que crear unha keystore de sinatura
e engadir unha configuración `release`.
